# NEHAM NGO Website

Static, multi-page NGO website designed for GitHub + Vercel deployment.

## Included
- Home
- About
- Programmes
- Impact
- Resources
- Stories
- Events
- Partners
- Get Involved
- Store
- Comics
- Reports & Transparency
- Donate
- Get Help
- Contact
- Privacy
- 404 page
- Responsive CSS
- Small vanilla JS file
- NEHAM logo asset

## Deploy
1. Create a GitHub repository.
2. Upload the contents of this folder.
3. Import the repository into Vercel.
4. Framework preset: Other / Static.
5. Build command: leave empty.
6. Output directory: `.`

## Before launch
Replace placeholder contact details, impact numbers, partner logos, photos, reports, store catalogue and donation gateway. Connect forms to the organisation's approved CRM/email endpoint. Review privacy, safeguarding, legal and financial wording before publishing.

## Reference direction
The information architecture takes cues from the supplied Red Dot Foundation and Equal Opportunity Community Initiative sites: clear issue/programme sections, impact, stories, resources, partners, action, donation and store pathways. It does not copy their text or branding.
